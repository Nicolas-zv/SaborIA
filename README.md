
# SaborIA 

**Sistema inteligente de análisis de sentimientos de reseñas de restaurantes**

## Descripción

SaborIA es una aplicación web en desarrollo que utilizará técnicas de Procesamiento de Lenguaje Natural (NLP) y Machine Learning para analizar reseñas de restaurantes y clasificarlas según su sentimiento: positivo, negativo o neutral.

## Objetivo general

Desarrollar una aplicación web capaz de analizar automáticamente las opiniones escritas por los clientes de restaurantes, aplicando técnicas de NLP y modelos de clasificación supervisada.

## Tecnologías

- Python
- Jupyter Notebook
- Pandas y NumPy
- NLTK y spaCy
- Scikit-learn
- FastAPI (previsto)
- HTML, CSS y JavaScript (previstos)
- Git y GitHub

## Modelos de Machine Learning previstos

- Naive Bayes
- Regresión logística

## Estructura del proyecto

- `data/`: datasets de reseñas.
- `notebooks/`: análisis exploratorio y experimentos.
- `src/`: procesamiento NLP y entrenamiento.
- `backend/`: API REST.
- `frontend/`: interfaz web.
- `models/`: modelos entrenados.
- `tests/`: pruebas automatizadas.
- `docs/`: documentación técnica.

## Instalación

```powershell
git clone https://github.com/Nicolas-zv/SaborIA.git
cd SaborIA
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```
